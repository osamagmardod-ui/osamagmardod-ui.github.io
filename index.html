About the data

Roster reference: RSLTools champion catalogue (reported 1,047 entries) and metadata enrichment from Goctionni/raid-data. If browser CORS blocks RSLTools, the site falls back to the community dataset. This starter does not scrape guide sites or copy their ratings. Verify all game data, images, and usage permissions before using the project commercially. This is an unofficial fan project and is not affiliated with or endorsed by Plarium.
